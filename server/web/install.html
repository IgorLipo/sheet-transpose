Transpose Chart

Share a chart from ForScore, pick a key, get it back transposed.

Add the Shortcut Open the web app

Setting it up

  1. Tap Add the Shortcut. Shortcuts opens; tap Add Shortcut.
  2. The first run asks to allow the connection to the Air — tap Allow.
  3. Make sure Tailscale is connected, or the Air is unreachable.

If the shortcut does nothing

Build it by hand instead — it takes a minute and always works. In Shortcuts → +:

  1. Tap the ⓘ info button → turn on Show in Share Sheet. Under Share Sheet Types, leave Files ticked.
  2. Add action Get Contents of URL. Tap Show More.
  3. URL: paste the line below, then delete the word KEY at the end and in its place insert the Ask Each Time variable.
  4. Method: POST. Request Body: File. File: choose the Shortcut Input variable.
  5. Add action Open In… (search “open in”) so the result comes back to the share sheet.
  6. Name it Transpose Chart. Done.

On a gig

  1. In ForScore, open the chart → Share → Transpose Chart.
  2. Pick the key.
  3. When it comes back, choose ForScore to file it with the rest.
The Air has to be awake and on the tailnet. Every transposed chart is also kept in the web app’s library, so you can pull it down again later.
