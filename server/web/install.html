Transpose Chart

Share a chart from ForScore, pick a key, get it back transposed.

Add the Shortcut Open the web app

Setting it up

  1. Tap Add the Shortcut. Shortcuts opens; tap Add Shortcut.
  2. The first run asks to allow the connection to the Air — tap Allow.
  3. Make sure Tailscale is connected, or the Air is unreachable.

On a gig

  1. In ForScore, open the chart → Share → Transpose Chart.
  2. Pick the key.
  3. When it comes back, choose ForScore to file it with the rest.
The Air has to be awake and on the tailnet. Every transposed chart is also kept in the web app’s library, so you can pull it down again later.
